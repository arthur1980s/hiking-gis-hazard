户外徒步路线态势感知与自然灾害交叉预警系统

规格说明，系统是纯前端PWA + GIS空间计算引擎，VPS只需要承担静态文件托管 + API代理转发的角色，非常轻量。


│
├── 一、应用壳 (App Shell)
│   ├── 顶部导航栏 (Logo + 标题 + 状态指示)
│   ├── 主内容区 (地图 + 控制面板)
│   └── 底部状态栏 (风险等级 + 坐标信息)
│
├── 二、核心功能模块
│   ├── 1. GPX轨迹上传区
│   │   ├── 拖拽上传区域
│   │   ├── 文件选择按钮
│   │   └── 示例轨迹加载
│   │
│   ├── 2. GIS地图引擎 (Leaflet + Turf.js)
│   │   ├── 底图切换 (地形图/卫星图/暗黑风)
│   │   ├── 轨迹显示 (GPX解析后绘制)
│   │   ├── 10km缓冲区 (动态生成)
│   │   └── 图层控制 (等高线/灾害点/雷达)
│   │
│   ├── 3. 灾害碰撞检测引擎
│   │   ├── 山火热点 (NASA FIRMS模拟数据)
│   │   ├── 地震点 (USGS模拟数据)
│   │   └── 气象预警 (模拟区域)
│   │
│   ├── 4. 微气象与风寒指数
│   │   ├── 轨迹海拔剖面图
│   │   ├── 风寒指数计算器
│   │   └── 高海拔风险预警
│   │
│   └── 5. 风险评估报告面板
│       ├── 综合风险等级 (绿/黄/红)
│       ├── 风险详情列表
│       └── 导出报告按钮
│
├── 三、PWA支持
│   ├── manifest.json (待补充)
│   └── Service Worker (待补充)
│
└── 四、数据层 (IndexedDB)
    ├── 历史轨迹存储
    └── 用户设置保存
    
    
    技术栈推荐
功能	推荐库	说明
地图渲染	Leaflet.MarkerMotion	轻量，适合 PWA
空间计算	Turf.js	纯前端 GIS 引擎，零后端负担
GPX 解析	@mapbox/togeojson	将 GPX 转为 GeoJSON
图表展示	Chart.js	海拔剖面图、风险统计
报告导出	html2canvas	截图生成简报
图标	Font Awesome	风险等级图标
